# WebUntis API icon concepts

All concepts are native, self-contained SVGs designed for T3 Code's compact project UI. Each uses a square canvas, an opaque background, thick shapes, and no font dependency.

**Selected direction:** Open Gateway. The production asset lives at [`../icon.svg`](../icon.svg) and is configured in the repository's `t3.json`.

1. **Schedule Signal** — a timetable crossed by a live data pulse; direct and technical.
2. **Open Gateway** — an architectural portal with API lanes; warm and editorial.
3. **Orbital W** — a bold monogram with a data orbit; energetic and brand-like.
4. **Layered Client** — an isometric stack combining schedules, code, and typed layers.
5. **Sentinel Owl** — a friendly read-only guardian studying a timetable.

The selected direction is configured in `t3.json`:

```json
{
  "$schema": "https://t3.codes/schema/t3.json",
  "iconPath": "assets/icon.svg"
}
```
